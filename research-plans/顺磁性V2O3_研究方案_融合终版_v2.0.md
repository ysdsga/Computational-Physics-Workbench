## 0. 方案边界与核心变更说明

### 0.1 本方案要复现什么

复现 Held (2001) 与 Keller (2004) 对顺磁性 V₂O₃ 建立的**三轨道 t2g LDA+DMFT 物理图景**：

1. 费米能附近的低能关联子空间由 1 个 a1g + 2 个 egπ 轨道组成（共 3 轨道/V × 4 V = 12 Wannier）；
2. 每个 V 离子的三轨道总占据 ≈ 2.0（V³⁺ d²）；
3. 在 U = 5.0 eV、J = 0.93 eV、β = 10 eV⁻¹ 附近，PM 结构处于强关联金属或金属—绝缘体转变边缘；
4. egπ 轨道占据显著高于 a1g（轨道极化）；
5. 随 U 从 4.5 eV → 5.5 eV，体系由金属逐渐演化为近 Mott 绝缘状态。

## 一、研究目标

### 1.1 总体目标

建立一条可审计、可重复、可与 Held/Keller 文献比较的顺磁性 V₂O₃ 三轨道 LDA+DMFT 工作流：

```
实验 PM 结构 (R-3c)
    ↓
LDA 非磁性 SCF (nspin=1)
    ↓

    ↓

    ↓

    ↓
三轨道 Kanamori DMFT (cthyb) · U 扫描 4.5/5.0/5.5
    ↓
轨道占据 / 自能 / Z / 谱重 / 多重态分析
    ↓
与 Held (2001) / Keller (2004) 对比
```

### 1.2 分阶段目标

**固定参数**：J = 0.93 eV，β = 10 eV⁻¹

**U 扫描**：U = 4.5, 5.0, 5.5 eV

对应 U' = U − 2J：

| U (eV) | U' (eV) | 预期物态 |
|---|---|---|
| 4.5 | 2.64 | 强关联金属 |
| 5.0 | 3.14 | 金属—绝缘转变边缘 |
| 5.5 | 3.64 | 近 Mott 绝缘 / 强赝隙 |

### 1.3 可证伪假设

**假设 H1：轨道极化**
- n(egπ) > n(a1g)
- n(a1g) + n(egπ,1) + n(egπ,2) ≈ 2.0

> **数值待核验**：GPT 修改版给 n(a1g) ≈ 0.37、n(egπ) ≈ 0.815；Gemini 修改版给 n(a1g) ≈ 0.54、n(egπ) ≈ 0.73。**两版数值冲突**，均自称引自 Keller 2004 但对不上。本方案不采信任何一方的具体数值，仅保留定性假设 n(egπ) > n(a1g)，待计算完成后与 Keller 2004 原文 Table 直接核对。

**假设 H2：金属—绝缘演化**
随 U 从 4.5 → 5.5 eV，准粒子权重 Z 单调下降，低能谱重 −(β/π)G(β/2) 显著抑制。

## 二、理论背景

### 2.1 体系描述

| 项 | 取值 |
|---|---|
| 化学式 | V₂O₃ |
| 相 | 高温顺磁金属相（PMM, T > 350 K） |
| 空间群 | R-3c (No. 167) |
| 晶系 | 菱面体（rhombohedral setting） |
| 原胞原子数 | 10（4 V + 6 O） |
| 价电子数 | 8（4 × V³⁺ d²） |
| 晶格矢量 (Å) | a1 = (2.476, −1.429, 4.668), a2 = (0, 2.859, 4.668), a3 = (−2.476, −1.429, 4.668) |

V₂O₃ 是 Mott 相变的经典范例：低温反铁磁绝缘体 (AFMI) → 高温顺磁绝缘体 (PMI) → 高温顺磁金属 (PMM)。本方案复现 PMM 态。

### 2.2 为何选择 3 轨道 t2g 模型

1. **晶体场分裂**：在 R-3c 结构中，八面体畸变使 V 3d 分裂为低能 t2g 组和高能 egσ 组（ΔCF ≈ 2.5–3.0 eV）；
2. **费米面主导性**：O 2p 位于 EF − 8 至 EF − 2 eV，V egσ 主要在 EF + 2.5 eV 以上。费米能级附近能带**完全**由 4 个 V 的 t2g（1 个 a1g + 1 组双重简并 egπ）构建；
3. **与 Held/Keller 对齐**：Held (2001) 与 Keller (2004) 正是基于 3 轨道 LDA 能带抽取 t2g 紧束缚模型（4 V × 3 t2g = 12 条带）开展 QMC 计算；
4. **计算可行性**：3 轨道比 5 轨道 cthyb 符号问题更弱，统计精度更高。

### 2.3 相互作用 Hamiltonian

Kanamori 形式：

  H_int = U Σ_m n_{m↑} n_{m↓}
        + U' Σ_{m<m', σ≠σ'} n_{mσ} n_{m'σ'}
        + (U'−J) Σ_{m<m', σ} n_{mσ} n_{m'σ}

其中 U' = U − 2J。本方案参数：U = 5.0 eV, J = 0.93 eV, U' = 3.14 eV

### 2.4 双计数

- **dc_type = 0**（FLL，fully localized limit）；
- **dc_dmft = false**（one-shot 框架下用 DFT 密度而非 DMFT 密度做双计数）；
- 目标占据：N_target = 8（总价电子），N_d = 2（每 V 的 t2g 占据）。

### 2.5 关键物理量

| 量 | 物理意义 | 预期（U=5.0） | 备注 |
|---|---|---|---|
| Z_m = [1 − ∂ImΣ_m(iω)/∂ω\|_{ω→0}]⁻¹ | 准粒子权重 | 0.3–0.5 | <1 即关联 |
| n(a1g), n(egπ) | 轨道占据 | n(egπ) > n(a1g)，和 ≈ 2.0 | 见 1.3 待核验说明 |
| ⟨n_{m↑}n_{m↓}⟩ | 双占据数 | 0.3–0.5 | per orbital |
| ImΣ(iω_n → 0) | 自能虚部 | 有限非零 | 金属态判据 |
| −(β/π)G(β/2) | 低能谱重 | 有限（金属）/ 趋零（绝缘） | 区分金属/绝缘 |
| P(N=2, S=1) | 局域 d² 高自旋多重态 | 占主导 | V³⁺ 局域组态 |

> **文献数值说明**：上表预期区间为定性范围，引自 Held (2001)/Keller (2004) 的物理图景。具体的 Z(a1g)、Z(egπ)、n(a1g)、n(egπ) 精确数值待计算完成后与 Keller 2004 原文 Table 直接核对，本方案不预采信 GPT/Gemini 修改版中互相冲突的具体数值。

### Stage 4 — 结果检查 (check)

1. **Z 提取算法**（采自 Gemini 修改版）

   由于 Matsubara 虚轴点在低频区有展宽效应，按二次多项式拟合前 4 个 Matsubara 频率点 ω_n = (2n+1)π/β：

   ```
   Im Σ(iω_n) ≈ a0 + a1·ω_n + a2·ω_n²    (n = 0,1,2,3)
   ```

   提取导数与准粒子权重：
   ```
   d ImΣ(iω_n)/dω_n |_{ω_n→0} ≈ a1
   Z = 1 / (1 − a1)
   ```

   ω_0 = π/β ≈ 0.314 eV（β=10 时）

2. **检查 observables_imp0.dat**（每个 U 点）
   - 关注列：iteration, mu, imp_occ, double_occ, Z (按轨道), ImΣ(0)
   - 判据：5 次 DMFT iter 后 Z 收敛到稳定值

3. **检查 conv_imp0.dat**
   - 自洽误差应单调下降或平台化
   - 若发散：见第六章风险决策树

4. **多重态分析**（采自 GPT 修改版）
   - 提取 P(N=2, S=1)：局域 d² 高自旋组态概率
   - ⟨S_z²⟩, ⟨S²⟩：验证局域自旋态
   - D_intra = Σ_m ⟨n_{m↑}n_{m↓}⟩：单轨道双占据
   - D_pair = ½⟨N(N−1)⟩：对占据

## 六、讨论与决策记录

### D1. 为何 3 轨道 t2g 而非 5-d 全轨道？

- **物理**：egσ 在 EF+2.5 eV 以上，与费米面物理无关；3 轨道是 Held/Keller 原文做法；
- **计算**：3 轨道 cthyb 符号问题更弱（Average Sign 预期 0.85–0.95），统计精度更高；
- **代价**：需新建 .win/.inp/.toml 三套文件（见 Stage 0），但 DFT 层完全复用。

### D2. 为何 J = 0.93 eV（改自 v1.1 的 0.96）？

- Keller 2004 原文用 J = 0.93 eV（constrained LDA 结果）；
- v1.1 的 0.96 eV 无明确出处，可能是 AI 凭印象写的；
- 忠实复现必须用原文值。U' = U − 2J = 5.0 − 1.86 = 3.14 eV。

### D3. 为何 U 扫描 4.5/5.0/5.5？

- 单点 U=5.0 只能看到一个物态，无法验证金属→绝缘演化；
- Keller 2004 Fig. 5 展示了 U 扫描的相变图景；
- 3 个点足以覆盖金属→边缘→绝缘三个区域，计算量可控（3 × 12h = 36h HPC）。

### D4. 为何选 cthyb 而非 hub1/hubbard-I？

- V t2g 在 d²、β=10 下符号问题可控（cthyb 可行）；
- cthyb 给出完整 G(iω)，可做 tail fit → 解析自能 → 直接读 Z；
- hub1 适合金属弱关联，hubbard-I 适合原子极限，均不适合 V₂O₃ 中等关联。

### D5. dc_type = 0 (FLL) 的取舍

- FLL 对应完全局域极限，是 cthyb + Kanamori 的标准选择；
- dc_dmft = false（用 DFT 密度而非 DMFT 密度做双计数），与 one-shot 框架自洽。

### D6. 风险调优决策树（采自 Gemini 修改版）

```

                              │
             ┌────────────────┴────────────────┐
             ▼                                 ▼
   [Im Σ(iω_n) 低频发散]               [化学势 μ 震荡不收敛]
   (出现伪绝缘体特征)                   (单位迭代 μ 变化 > 0.05 eV)
             │                                 │
     ┌───────┴───────┐                 ┌───────┴───────┐
     ▼               ▼                 ▼               ▼
[降低 U 至 4.5eV] [检查 dis_win]  [设 prec_mu=1e-3] [用 nominal DC]
(文献可能存在    (确认没混入       (放宽 μ 精度)    (固定 DC 势)
 视角差异)        egσ 态)
```

**具体风险表**：

| 风险 | 备份方案 |
|---|---|
| Wannier band 在冻结窗外显著偏离 DFT band | 调 dis_win 至 [11.0, 16.5] eV，或加 site-symmetry 约束 |
| cthyb 符号问题严重（Average Sign < 0.7） | 检查 Kanamori 矩阵是否含 spin-flip + pair-hopping；或降 U 至 4.5 |
| Z 不收敛 | 增大 n_iter_dmft 至 8，或检查 tail fit 窗 [8,16] |
| n(a1g) < 0.2（轨道被压掉） | 检查 t2g 投影的局部坐标系；V₂O₃ 菱面体畸变沿 [111] 方向 |
| μ 震荡 | prec_mu 放宽至 1e-3，或用 nominal DC |
| 3 轨道结果与 Keller 数值不符 | 核对 Keller 2004 原文 Table（GPT/Gemini 数值冲突，以原文为准） |

### D7. 与现有 Workbench 模板的差异

| 模板默认 | 实际值 | 影响 |
|---|---|---|
| `solid_dmft.py dmft_config.ini` | `solid_dmft.py v2o3_t2g_config.toml` | 文件后缀 + 配置格式（TOML） |
| `conv_thr 1e-6` (模板) | `1e-10` (实际) | 实际更严，应保留 |
| `prec_mu` 未在模板体现 | `1e-4` | 写入模板 |
| `perform_tail_fit` 未在模板体现 | `true` + `fit_max_moment=4` | 写入模板 |

> **建议**：将 Workbench 中 `One-shot DFT+DMFT` 模板的 dmft-03 步骤补充 tail fit 字段，配置后缀统一为 `.toml`。
