# HPCPlus 网页终端桥接协议

## 边界

桥接层只对已打开、已登录、已连接的 Edge PWA 终端窗口做本地 UI Automation：定位终端、粘贴一条命令、读取当前可访问性文本。它不访问门户 API，不读取 DOM，不导航菜单，也不上传或下载文件。

## 执行协议

1. 精确匹配窗口标题 `HPCPlus平台`。
2. 要求找到 `AutomationId=dummy` 的 xterm 输入控件和 `ClassName=terminal` 的终端区域；没有可靠定位时立即失败。
3. 使用本地互斥锁防止两条命令同时操作窗口和剪贴板。
4. 将原始命令编码为 UTF-8 Base64，再包装为单行 `bash -lc` 命令，避免原始命令破坏标记协议。
5. 输出随机开始/结束标记和远端退出码；只有同一次执行的开始标记已出现后，结束标记才有效，孤立或陈旧结束标记不能证明完成。
6. 仅轮询本地 UI Automation 文本树，直到完整标记对出现或超时；同时只检查新出现的可访问性文本中的精确 `403 Forbidden`、SSCT 断线和会话过期信号。轮询不会请求 HPCPlus HTTP 接口。
7. 剪贴板读取、写入和恢复都采用有界重试；命令发送后恢复原剪贴板内容和鼠标位置。若远端命令已发送而剪贴板恢复最终失败，不再丢弃远端标记结果，而是在结构化结果中记录本地警告。
8. 每次执行必须由独立参数提供已确认、规范化且非根目录的绝对 POSIX 工作目录；桥接器先进入该目录并核对 `$PWD`，再把整条用户命令作为一个受保护的命令组执行，避免分号等 shell 分隔符绕过目录守卫。用户命令只能使用相对路径，显式绝对路径、`~`、`$HOME`、`$TMPDIR` 和 `$SCRATCH` 路径一律拒绝。
9. 成功、失败和超时结果默认最多返回末尾 160 行、65,536 个字符；发生截断时写入明确标记。

工作台 Task Spec 执行器在发送前重新读取本地 API，只接受 `ready` 状态和当前内容哈希。它在发送前创建一次不可覆盖的 command run，并将桥接结果写回：退出码 0 进入 `verifying` 等待人工科学验证，远端非零退出进入 `failed`，超时或发送后桥接异常进入 `unknown`。`unknown` 不会自动重试。

若工作台服务在审计记录仍为 `executing` 时重启，启动恢复事务将遗留 command run 与 scheduler poll 保守结束为 `unknown` 并停止关联 Task Spec；遗留 bounded log read 只结束该读取事件。恢复原因和结束时间进入审计记录，恢复过程不触碰网页终端且不重发命令。

LSF 提交是例外：只有解析到 `Job <数字> is submitted` 才进入 `monitoring`。状态查询由服务端生成 `bjobs -noheader -o stat <job_id>`，在发送前创建 poll event 并锁定下一个允许时间；两次尝试至少间隔 60 秒。`DONE` 进入科学验证，`EXIT/ZOMBI` 进入失败，无法识别、断线、超时或 `UNKWN` 进入 `unknown` 并停止。

日志读取只能提供相对路径和 1–200 行。服务端拒绝绝对路径、`..`、通配符与控制字符，在 Task Spec 已审批目录内生成单条 `tail` 命令，并使用独立的 60 秒节流和不可变 log event。日志读取失败只记录该次读取的 failed/unknown，不会自动重发或改变计算参数。

## 风险分类

- 默认允许：`hostname`、`whoami`、`pwd`、`module avail`、`conda env list`、`bjobs`、`qstat`、`squeue`、有界的 `tail`/`head`/`cat`。
- 需要 `-AllowSubmit`：`bsub`、`sbatch`、`qsub`。
- 需要 `-AllowMutating`：重定向写文件、`mv`、`rm`、权限修改、终止作业等。
- 始终拒绝：交互编辑器/监视器、软件安装、网络下载、SSH/文件传输工具。
- 始终拒绝：缺少已确认工作目录、用户命令内切换目录、显式绝对或 home-relative 路径、`..` 越界、递归文件扫描、后台运行，以及 `eval`、`bash -c` 等间接执行。审计执行器通过独立参数设置 Task Spec 已审批目录，并在执行命令前核对 `$PWD`；绑定的 LSF 脚本仅允许保留一行与该目录完全相同的独立 `cd` 指令。

风险分类是防误操作护栏，不是 shell 安全沙箱。执行前仍需人工审阅完整命令。

## 失败处理

- 找不到精确窗口、终端或输入控件：停止，用户重新打开并聚焦正确终端。
- 缺少开始标记、结束标记，或标记顺序错误：停止；不要自动重复发送，因为上一条命令可能仍在运行。
- 输出过长：改为远端写入日志后执行一次 `tail -n N`。
- 长任务：通过 LSF 提交，之后低频查询调度状态，不保持桥接调用等待计算结束。
- 页面刷新、会话过期、断线或精确 `403 Forbidden`：立即返回 `unknown` 并停止所有自动操作，由用户恢复会话。历史断线消息后若出现更新的已连接标记，不把旧消息误判为当前故障。
