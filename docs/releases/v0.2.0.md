# Computational Physics Workbench v0.2.0

**Open Community Preview · 开放社区预览版**

## 中文

Computational Physics Workbench 是一个面向计算物理与理论物理的本地优先科研协作系统。研究者通过对话提出科学问题、确认执行边界并审阅关键证据；Codex Agent 负责规划、执行、排错、远程作业监控和可追溯记录。

### 本版亮点

- 项目更名并明确扩展到一般计算物理与理论物理，而不局限于 DFT+DMFT；
- 发布项目级 `workbench-agent`、`literature-research` 与 `theory-derivation` Skills；
- 增加物理文献复现工作流，并保留 One-shot DFT+DMFT、模型 DMFT 与理论研究模板；
- 完善首次使用、长时间研究、远程计算与贡献路线图文档；
- 通过 Confirmed Envelope、Task 写根、Action/Job/Evidence 账本约束本地与 HPC 执行；
- 增加架构与界面展示，以及 AI4Physics 社区交流入口。

当前经过验证的参考路径是 **Codex + OpenSSH/SFTP + IBM LSF**。Slurm、PBS 和其他 Agent 客户端仍需要适配与真实测试。本项目仍是早期研究预览版，接口、数据模型和工作流约定可能变化。

## English

Computational Physics Workbench is a local-first research collaboration system for computational and theoretical physics. Researchers define scientific questions, confirm execution boundaries, and review decisive evidence; a Codex agent plans and executes the work, diagnoses failures, monitors remote jobs, and maintains a traceable research record.

### Highlights

- Renamed and broadened the project beyond its original DFT+DMFT use case;
- Published project-local `workbench-agent`, `literature-research`, and `theory-derivation` skills;
- Added a physics-literature-reproduction workflow alongside DFT+DMFT, model-DMFT, and theoretical-research templates;
- Added first-run, long-running research, remote-compute, contribution, and roadmap documentation;
- Enforced bounded local/HPC execution through confirmed Envelopes, Task roots, and an Action/Job/Evidence ledger;
- Added architecture and interface previews plus an AI4Physics community entry.

The validated reference path is currently **Codex + OpenSSH/SFTP + IBM LSF**. Slurm, PBS, and other agent clients still require adapters and real-world validation. This remains an early research preview: interfaces, data models, and workflow conventions may change.
